# Student Event Registration Portal

A responsive student event registration website built using HTML5, CSS3 and JavaScript.

## Features
- Responsive design for mobile, tablet and desktop
- Upcoming event listing
- User-friendly registration form
- Client-side input validation
- Error messages for invalid/missing data
- Registration confirmation and generated Registration ID
- Registration tracking using localStorage
- No backend required for this demo

## How to run in VS Code
1. Extract/open this folder in VS Code.
2. Install the Live Server extension.
3. Open `index.html`.
4. Right-click `index.html` and choose **Open with Live Server**.
5. Test the form in your browser.

## Technologies
HTML5, CSS3, JavaScript
